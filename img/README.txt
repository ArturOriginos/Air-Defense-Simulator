Сюда можно положить фото систем ПВО. Имя файла = id системы, формат .jpg:
osa, s300, pantsir, tor, buk, iron, nasams, iris, patriot, s400
(например img/patriot.jpg, лучше 480x360). Если файла нет, в магазине показывается флаг страны.
Используй изображения, которые можно свободно использовать (например, с Wikimedia Commons).
